# belove beauty — Creative Reference Link

Social Content Direction — Vol. 01

Built by Inloop Media

---

A single-page moodboard / social content direction site for **belove beauty** — a
self-love beauty brand with clean, skin-safe formulas made for every skin, every shade,
every story. Brand identity (crimson wordmark, blush-and-crimson theme, Fredoka + Jost
typography) taken from the belove beauty brand guidelines; content pillars and reference
links supplied by Inloop Media.

- **Display type:** Fredoka (editorial match for Morl) · **Body:** Jost (match for Futura) · **Accents:** Playfair Display (match for Minion)
- **Palette:** blush `#fff6f8` ground, crimson `#BF0D3E` accent (Pantone 193C), rose `#D25B73`, soft pink `#E68699`
- **Pillars:** Founder Diaries · Shade Proof · Beauty Education · Belove Circle · Brand Moments
- **Grid:** 12 reference pieces (reels, statics + carousels) with pillar filters and a lightbox gallery
